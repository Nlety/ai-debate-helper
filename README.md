## 项目简介

AI 辩论助手帮助生成辩论观点、论据和逻辑分析，支持正方、反方或双方分析。

## 核心功能

- 🎯 **辩论观点**：正方/反方论点生成
- 📊 **多深度分析**：快速要点到深度论证
- 🔄 **反驳预案**：预判对方观点和应对
- 💡 **辩论技巧**：表达建议
- 💾 **保存记录**：收藏辩论分析

## 本地运行

直接用浏览器打开 `index.html` 即可使用。
